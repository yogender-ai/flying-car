# "What is Agentic AI?" — 20-second vertical video

Format: 9:16 vertical (1080 × 1920), 5 scenes × ~4 seconds.
Save each image you generate into the `images/` folder with the exact name shown
(`scene1.png` … `scene5.png`, .jpg/.webp also fine). Then tell Claude "images done".

## How to use the prompts

- **ChatGPT:** paste one prompt per message. If the image comes out square, reply
  "make it vertical 9:16, same image".
- **Gemini:** paste the prompt and start it with "Generate an image:".
- Do all 5 images **in the same chat**, so the robot looks the same in every scene.
  After image 1, you can add: "Use the exact same robot character and style as before."
- If any image contains words or letters, ask: "remove all text from the image".
